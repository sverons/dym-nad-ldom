# Как перенести «Дым над льдом» в Claude

1. Распаковать архив в корень проекта, где уже лежат ваши агенты Claude.
2. Не удалять существующую папку `.claude/agents/`.
3. Запускать Claude Code из корня проекта.
4. Выполнить `/memory` и убедиться, что загружен корневой `CLAUDE.md`.
5. При работе в папке конкретной главы Claude дополнительно использует вложенный `CLAUDE.md`.
6. Старые черновики помещать в `source/`, а актуальные изменения — в `docs/`.

## Проверка после установки

Попросите Claude без добавления новых фактов ответить:
- кто убил Анну;
- в чём виновен Сергей;
- какова истинная серия KAPNOS;
- почему Крылов ложное звено;
- чем заканчивается первая глава.

Правильно: Анну убил Виктор; Сергей убил Веронику, но не Анну; серия — Морозов → Мия → Анна; у Крылова другая марка сигарет; первая глава заканчивается обнаружением тела Вероники.
