# Коробка «Железный трон» — 110×70×40 мм

Базовая версия (трон на крышке) + **8 вариантов** в [`variants/`](variants/).

## Базовая версия

| Файл | Назначение |
|------|------------|
| `got_card_box_base_110x70x40.stl` | Лоток |
| `got_card_box_lid_110x70x40.stl` | Крышка с троном |
| `got_card_box_closed_preview_110x70x40.stl` | Макет |
| `generate_got_box.py` / `generate_variants.py` | Пересборка |

## Варианты (`variants/`)

| # | Папка | Идея |
|---|-------|------|
| 01 | `01_end_throne` | Трон на торце, крышка — пластины |
| 02 | `02_crossed_swords` | Скрещённые мечи + корона |
| 03 | `03_forge` | Кузня + мелкий медальон |
| 04 | `04_ice_fire` | Лёд / пламя |
| 05 | `05_wolf_throne` | Северный трон + геом. волк |
| 06 | `06_dragon_bone` | Драконьи рёбра / чешуя |
| 07 | `07_minimal` | Контур line-art |
| 08 | `08_two_layer` | Пластины + отдельный апплике |

В каждой папке: `*_base.stl`, `*_lid.stl`, `*_preview.stl`, `preview.png`.  
У варианта 08 дополнительно `*_applique.stl`.

## Печать

- Единицы: мм, слой 0.16–0.2 мм, рельефом вверх  
- Чёрный/металлик PLA + сухая кисть под кованое железо  
- Зазор крышки: 0.35 мм (`CLEARANCE`)
