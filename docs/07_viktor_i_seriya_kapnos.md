# Виктор Иванов и серия KAPNOS

Виктор Иванов — врач-офтальмолог, связанный с «ProЗрение». Он сам не курит, но заказывает KAPNOS.

KAPNOS для Виктора — символ детского ужаса: отец, сигаретные ожоги, пожар, приёмный отец, насилие.

## Истинная серия

2. Мия.
3. Анна.

## Ложное звено

Крылов. Он похож на жертву серии сценически, но сигарета не KAPNOS.
