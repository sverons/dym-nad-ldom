# Старые исходные истории

В эту папку можно положить старые биографические и сюжетные черновики.

Важно: старые истории являются эмоциональным источником, но не финальным каноном.

При конфликте со свежими файлами приоритет имеют:
1. `docs/12_chto_nelzya_menyat.md`
2. `docs/03_kanon.md`
3. `docs/04_glava_1_struktura.md`
4. `docs/06_glava_2_struktura.md`

Старые истории использовать для эмоционального фона, мотиваций, речи персонажей, биографических деталей и атмосферы.
