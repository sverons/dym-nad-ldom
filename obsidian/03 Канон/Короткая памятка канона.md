| Вопрос | Ответ |
| --- | --- |
| Кто убил Анну? | Виктор Иванов. |
| Кто убил Веронику? | <span style="color:#e03131">Сергей Якунин</span> → в [[Авторская библия|библии]]: [[Сергей Акунин|Акунин]], по признанию. |
| Вероника причастна к Анне? | Нет как факт. Только версия следствия/ложный след. |
| Кто серийный убийца? | Виктор Иванов, врач-офтальмолог ProЗрение. |
| Сколько настоящих убийств в серии? | Три: Морозов, Мия, Анна. |
| Крылов входит в серию? | Нет. Это ложная жертва/ложная связка. |
| Ключевая сигаретная марка? | KAPNOS. У Крылова — другая марка. |
| Виктор курит? | Нет. |
| Мия — сокращение? | Нет. Мия — полное имя. |
| Главная драматургическая формула | Сергей виновен, но не в главном убийстве; настоящий убийца спрятан за слишком очевидной семейной версией. |

Примечание: документ фиксирует текущую рабочую версию канона. Все новые сцены, улики и допросы должны сверяться с разделами «Закреплённые правила канона» и «Что нельзя ломать».
